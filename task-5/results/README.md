# Задание 5. Проектирование и реализация выбранных решений для мониторинга, оповещения и логирования

## Решение

Расширяется архитектура задания 4. Монолит, Spring Batch, обе PostgreSQL и GCS сохраняются.

Prometheus собирает метрики, Grafana показывает дашборды и отправляет оповещения. Для логов выбран ELK: Elasticsearch хранит записи, Logstash обрабатывает их, Kibana позволяет искать ошибки. Filebeat читает логи приложений и передает их в Logstash.
Так можно видеть состояние системы и искать ошибки по отчету в одном месте, а не просматривать логи каждого приложения отдельно.

## Метрики

| Что измеряем | Источник | Зачем |
| --- | --- | --- |
| Количество принятых, успешных и неуспешных отчетов | Таблица заданий и Spring Batch | Видеть нагрузку и результат обработки, отделять ошибки данных от технических сбоев |
| Время от регистрации отчета до завершения, отдельно время выполнения | Таблица заданий и Spring Batch | Проверять цель до 30 секунд для отчета из 2 000 строк и учитывать ожидание в очереди |
| Количество ожидающих и активных заданий, возраст самого старого ожидающего задания | Таблица заданий | Обнаруживать очередь при пиковых загрузках и нехватку обработчиков |
| Прочитанные и записанные строки, ошибки проверки, повторные попытки | Шаги Spring Batch | Проверять объем обработки и замечать проблемы записи. Невалидные строки не пропускаются молча |
| Частота запросов, время ответа и доля ответов 5xx | Монолит | Проверять, что ERP не тормозит из-за фоновой обработки |
| Ошибки и длительность обращения к GCS | Клиенты GCS в монолите и сервисе обработки | Отличать проблемы хранения файлов от ошибок ETL |
| Память JVM, паузы сборщика мусора и загрузка CPU процесса | Монолит и сервис обработки | Находить нехватку ресурсов и причины задержек |
| Доступность, занятые соединения, блокировки и взаимные блокировки | Обе PostgreSQL | Контролировать нагрузку на БД номенклатуры и БД справочников отдельно |

Prometheus опрашивает приложения и сборщики статистики обеих БД. Выдачу метрик нужно настроить, а показатели очереди и полного времени обработки добавить в сервис Spring Batch на основе таблицы заданий.

Grafana показывает прием файлов, обработку и состояние ресурсов. Идентификаторы отчетов используются для поиска в логах, а не как метки метрик.

## Оповещения

Grafana отправляет уведомления дежурному DevOps по email. Начальные пороги уточняются после нагрузочного теста.

| Условие | Назначение |
| --- | --- |
| Приложение или БД недоступны более минуты | Обнаружить отказ. Доступность сборщика не заменяет проверку самой БД |
| За последние 5 минут появились технически неуспешные отчеты после всех повторов | Сообщить о сбое обработки |
| Среднее время успешных отчетов из 2 000 строк за 15 минут превышает 30 секунд | Проверять целевое время, если за период были такие отчеты |
| Самое старое ожидающее задание старше минуты в течение 5 минут | Обнаружить задержку или остановку обработки, даже если завершенных заданий нет |
| Доля 5xx выше 5% за 5 минут при наличии запросов | Обнаружить деградацию ERP |
| Память JVM или занятые соединения БД превышают 85% допустимого значения в течение 5 минут | Предупредить об исчерпании ресурсов |

Ошибки CSV показываются пользователю и записываются в логи, без письма дежурному на каждый неправильный файл. Потеря метрик от настроенного источника также требует уведомления.

## Логирование

Монолит и Spring Batch записывают JSON логи. Filebeat собирает их отдельно от приложений и отправляет в ELK.

| Данные в записи | Назначение |
| --- | --- |
| Время, уровень, сервис и экземпляр | Определить, когда и где произошло событие |
| Идентификатор отчета, запуска и название шага | Найти цепочку обработки от приема файла до результата |
| Событие, статус и длительность | Понять ход и итог выполнения |
| Число прочитанных и записанных строк | Проверить результат обработки |
| Код ошибки, номер строки и стек исключения для технического сбоя | Найти причину без записи содержимого CSV |

Общий идентификатор отчета передается от монолита в Spring Batch через таблицу заданий. Логируются прием файла, начало обработки, шаги, повторы и результат. Содержимое CSV, пароли, токены и персональные данные не записываются.
